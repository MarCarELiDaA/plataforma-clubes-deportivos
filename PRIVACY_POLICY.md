## 2. Información que Recopilamos

### 2.1 Información Personal
- **Nombre completo:** Requerido para identificación
- **Correo electrónico:** Requerido para autenticación y comunicaciones
- **Teléfono:** Opcional, para contactos de emergencia

## 3. Finalidad del Tratamiento

Utilizamos sus datos personales para:
- **Gestión de reservas:** Procesar y gestionar sus reservas de pistas
- **Autenticación:** Permitir el acceso a la aplicación
- **Comunicaciones:** Enviar notificaciones sobre sus reservas
- **Mejora del servicio:** Analizar patrones de uso para mejorar la aplicación
- **Seguridad:** Prevenir fraudes y proteger la cuenta del usuario

## 4. Base Legal

El tratamiento de sus datos se basa en:
- **Consentimiento:** Al registrarse en la aplicación
- **Ejecución de contrato:** Para proporcionar el servicio de reservas
- **Interés legítimo:** Para la seguridad y mejora del servicio

## 5. Compartición de Datos

No compartimos sus datos personales con terceros para fines comerciales, excepto:
- **Firebase (Google):** Para proporcionar servicios de autenticación y base de datos
- **Proveedores de servicios:** Solo cuando sea necesario para el funcionamiento de la app

## 6. Seguridad de Datos

Implementamos medidas de seguridad:
- ✅ Encriptación de datos en tránsito
- ✅ Autenticación segura con Firebase
- ✅ Control de acceso a datos
- ✅ Backups regulares
- ✅ Actualizaciones de seguridad

## 7. Derechos del Usuario (GDPR)

- **Acceso:** Solicitar copia de sus datos personales
- **Rectificación:** Corregir datos inexactos
- **Supresión:** Solicitar eliminación de sus datos
- **Portabilidad:** Recibir sus datos en formato estructurado
- **Oposición:** Oponerse al tratamiento de sus datos
- **Limitación:** Solicitar limitación del tratamiento

Para ejercer estos derechos, contacte: [email de contacto]

## 8. Retención de Datos

- **Datos de cuenta:** Mientras la cuenta esté activa

- **Datos técnicos:** 1 año después del último uso

## 9. Transferencias Internacionales

Sus datos pueden ser almacenados en servidores ubicados fuera de la UE (Firebase/Google), con las garantías adecuadas de protección de datos.

- Analizar el uso de la aplicación
